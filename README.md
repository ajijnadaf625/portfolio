# 🚀 Interactive ML/AI & Data Science Portfolio | Ajij Nadaf

Welcome to my portfolio! I am an **AI/ML Engineer & Data Science Analyst** specializing in python, SQL, machine learning, and data analytics. This portfolio showcases interactive 3D simulations of algorithms, real-world data science projects, and predictive analytics tools built using modern web development practices.

🌐 **Live GitHub Repository:** [ajijnadaf625/portfolio](https://github.com/ajijnadaf625/portfolio)

---

## 🌟 Key Highlights & Features

- 🔬 **Interactive 3D Algorithm Sandbox:** Custom-built 3D canvas engine (no external WebGL dependencies, using pure JavaScript depth-sorting and rotation projection) showcasing:
  - **Logistic Regression 3D:** Real-time decision boundary hyper-plane optimization using gradient descent.
  - **Random Forest 3D & XGBoost 3D:** Interactive ensemble classification trees and boosting decision boundaries.
  - **SMOTE 3D:** Visualizing synthetic oversampling to balance class distribution in 3D space.
  - **Face Recognition 3D:** Dynamic mapping of facial vector embeddings.
  - **House Regression 3D:** Surface fitting plane mapping sq ft, rooms, and valuation.
- 💻 **Interactive Live Simulators:** Play with live model simulators right inside the portfolio (Customer Churn Risk, Facial Scanner, and House Pricing Valuation).
- 🎨 **Premium Glassmorphism UI:** Responsive layout designed with a modern dark theme, smooth micro-animations, customizable responsive elements, and optimized rendering.

## 📁 Projects Featured

### 1. 📊 Customer Churn Prediction
* **Description:** Preprocessed Telco customer data, handled severe class imbalance using SMOTE, and trained/compared Logistic Regression, Random Forest, and XGBoost models.
* **Interactive Tool:** Built-in **Churn Risk Calculator** allowing users to adjust tenure, monthly charges, and contract type to see active risk probabilities and business recommendations.

## 🚀 Getting Started (Run Locally)

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### 1. Clone the Repository
```bash
git clone https://github.com/ajijnadaf625/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run in Development Mode
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the interactive portfolio.

### 4. Build for Production
```bash
npm run build
```
The output bundle will be generated in the `dist` folder.
